Panduan NoorSlide AI (Powered by Claude AI)

Otomatisasi konten dakwah visual dengan klasifikasi 3 cabang ilmu Islam

1. Mesin Anthropic Claude Messages API + Auto-Fallback

Aplikasi ini terhubung langsung ke https://api.anthropic.com/v1/messages menggunakan API Key Anda (sk-ant-...). Dilengkapi Auto-Retry (3x Exponential Backoff) jika server sibuk (HTTP 429/529) serta Multi-Model Fallback Chain otomatis antar seri Claude Sonnet & Haiku agar proses generate selalu berjalan lancar.

2. Deteksi Dalil Otomatis & Klasifikasi 3 Cabang Ilmu Islam

Tempel teks Hadits atau Ayat Al-Qur'an (teks Arab + terjemahan, terjemahan saja, atau cukup rujukannya seperti "QS. Al-Insyirah: 5-6" atau "HR. Muslim no. 2664"). Claude AI otomatis mendeteksi label kartu (♦ AL-QUR'AN ♦ / ♦ HADITS ♦) dan mengelompokkannya ke TAUHID (AKIDAH), FIQIH, atau TASAWUF (AKHLAK).

3. Unduh Foto Berurutan Tanpa ZIP (1080×1350 px)

Klik "Unduh Semua Foto Berurutan (PNG)" untuk langsung mengunduh seluruh slide satu per satu (01-cover.png, 02-poin-1.png, ..., 05-dalil.png, 06-penutup.png) dalam kualitas cetak 1080×1350 px.
